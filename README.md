# FitJourney

Aplicación móvil Android para la gestión y seguimiento de entrenamientos fitness.

## Funcionalidades

- Registro e inicio de sesión de usuarios
- Creación y edición de rutinas
- Gestión de ejercicios
- Perfil de usuario
- Seguimiento de entrenamientos

## Tecnologías

- Java
- Android Studio
- MVVM
- Retrofit
- REST API
- LiveData
- SQL
- Git

## Arquitectura

La aplicación sigue el patrón MVVM separando:
- View
- ViewModel
- Repository
- Data sources
